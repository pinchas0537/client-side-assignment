Full Stack Application - Client Side

**Technical Stack**
* **Library:** React.js
* **Language:** JavaScript/ES6+
* **Styling:** CSS3 / Modern UI Design
* **API Communication:** Axios 

**Key Features**
* **Component-Based Architecture:** Built with reusable React components for maintainability.
* **State Management:** Efficient handling of application data and user interactions.
* **Responsive Design:** Fully optimized for mobile, tablet, and desktop views.
* **Dynamic Routing:** Seamless navigation within the single-page application (SPA).
* **API Integration:** Real-time data synchronization with the Node.js backend.

**Getting Started**
Recommended Way: Docker (Full Stack)
For the best experience and to ensure all services (Backend, Frontend, and Database) are connected and configured correctly, use Docker Compose.
1. Clone the repositories:
git clone https://github.com/pinchas0537/server-side-assignment
git clone https://github.com/pinchas0537/client-side-assignment
2. cd server-sidt-assignment
3. docker compose up --build -d

For Local Development Only
If you are working on the code and need hot-reloading for local testing:

1. Backend: Navigate to server-side-assignment, configure your .env file, and run npm install && npm start.

2. Frontend: Navigate to client-side-assignment, ensure your API URL points to the running backend port, and run npm install && npm run dev.

Note: Please ensure the backend is running before starting the frontend.
